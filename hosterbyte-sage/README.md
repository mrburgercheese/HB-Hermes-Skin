## ⚡ Cara Pasang Cepat (1-Line Auto Installer)

### Linux / macOS / WSL:
```bash
curl -fsSL https://raw.githubusercontent.com/mrburgercheese/HB-Hermes-Skin/main/hosterbyte-sage/install.sh | bash
```

### Windows (PowerShell):
```powershell
irm https://raw.githubusercontent.com/mrburgercheese/HB-Hermes-Skin/main/hosterbyte-sage/install.ps1 | iex
```

---

## 🛠️ Instalasi Manual

1. Salin berkas `skin.yaml` ke direktori skins Hermes:
   - **Linux / macOS**: `~/.hermes/skins/hosterbyte-sage.yaml`
   - **Windows**: `%LOCALAPPDATA%\hermes\skins\hosterbyte-sage.yaml`
2. Aktifkan skin melalui CLI:
   ```bash
   hermes config set display.skin hosterbyte-sage
   ```
